# Tajamul Wani Portfolio

This repository contains the live portfolio website for Tajamul Wani, a Marketing Operations Engineer. The site showcases full-stack marketing infrastructure, CRM pipelines, funnel development, automation workflows, email systems, and Claude Code-assisted full-stack development.

## Overview

The site is a responsive, static portfolio built with HTML, CSS, and vanilla JavaScript. It features:

- Hero introduction with brand messaging and direct contact actions
- About section with skills, platform stack, and delivery focus
- Services section describing MarTech platforms, CRM and pipelines, email marketing, automation and API integrations, SEO and analytics, and Code, AI Dev and product tools
- Case studies highlighting B2B outbound prospecting, quiz-based lead segmentation, and marketing attribution and CRM automation for Wix
- Project showcase of live builds including LearnTopia, Newscryst, FormPing, GoHighLevel systems, and funnel implementations
- Contact section with a Netlify-powered submission form
- Footer with brand, copyright, and back-to-top interaction

## Current Work Highlight

- **LearnTopia** — e-learning platform with user authentication and course enrollment, expanded through Claude Code-assisted development
- **Newscryst** — Claude Code-assisted news experience deployed on Netlify
- **FormPing** — QA automation and website-monitoring tool with Slack alerting, Railway deployment, and Supabase database design
- **GoHighLevel marketing system** — full CRM/funnel implementation
- **ClickFunnels funnel development** — live funnel with order flow and automation
- **Charity WordPress website** — responsive WordPress delivery for a UK charity

## Tech Stack

- HTML5
- CSS3 (responsive layout, custom components)
- JavaScript (scroll spy, reveal animations, counters, project filters)
- Git and GitHub
- Linux
- Linear for product planning and issue tracking
- Playwright for browser testing
- Static deployment-friendly asset directory

## Files

- `index.html` — main portfolio page markup
- `style.css` — layout, styling, responsive breakpoints, theme
- `index.js` — page interactivity, sticky nav, reveal animations, project filtering
- `assets/` — image and logo assets used across the site
- `sitemap.xml` — page anchor URLs for search engines
- `robots.txt` — crawler instructions
