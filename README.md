# Tajamul Wani Portfolio

This repository contains the live portfolio website for Tajamul Wani, GTM Engineer.
## Overview

The site is a responsive, static portfolio built with HTML, CSS, and vanilla JavaScript. It features:

- Hero introduction with brand messaging and direct contact actions
- About section with skills, platform stack, and delivery focus
- Services section describing marketing operations, automation, funnels, email, landing pages, and integration work
- Case studies highlighting B2B outbound prospecting and quiz-based lead segmentation systems
- Project showcase of live builds including LearnTopia, Newscryst, FormPing, GoHighLevel systems, and funnel implementations
- Contact section with a Netlify-powered submission form
- Footer with brand, copyright, and back-to-top interaction


## Tech Stack

- HTML5
- CSS3 (responsive layout, custom components)
- JavaScript (scroll spy, reveal animations, counters, project filters)
- Static deployment-friendly asset directory

## Files

- `index.html` — main portfolio page markup
- `style.css` — layout, styling, responsive breakpoints, theme
- `index.js` — page interactivity, sticky nav, reveal animations, project filtering
- `assets/` — image and logo assets used across the site
- `sitemap.xml` — page anchor URLs for search engines
- `robots.txt` — crawler instructions

## Notes

The portfolio is intended to present a concise growth-systems brand narrative, with a focus on CRM automation, funnels, and AI-assisted product launches.
